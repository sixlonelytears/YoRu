# YoRu

case study đánh giá hiệu năng hệ thống

## chạy

buộc phải cần có sẵn Node.js trên máy:

```bash
git clone https://github.com/sixlonelytears/YoRu.git
cd YoRu
npm install
node server.js
```

local host `http://localhost:3000`.
